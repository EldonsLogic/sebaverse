# Direct digital-PDF adapter contract v1 — implementation brief

19 November 2026 · AUTH-013 / ADR-014 · DEV-010 · R039/R040/R041/R046. Root owns this brief. This is an internal worker core, not a public endpoint, SDK install, cleared runtime or live broker route. Existing RuntimeAssets remains unchanged/default-deny. No real native call in tests.

## Owned interface

Implement workers/parser/digital_pdf.py, importable with no PyPDFium2 installed. Export PARSER_ID = "pypdfium2-5.15.2-pdfium-159.0.8149.0-text-v1", WHEEL_SHA256 = the exact dc31aea5b0fb9fefc9b537a65f4113980b2c40798445736a7e6565bc85161e37, ExtractionError(ValueError), RuntimeUnavailable(ExtractionError), and run_job(data, envelope, job_key, expected, scan_envelope, scan_key, scanner_id, *, document_factory=None, now=None, clock=time.monotonic). Use the existing pure contracts sign/verify/canonical/validate_result and limits; never import Django, models, database or the native SDK at module import.

Expected is a server-supplied dict with exactly object_id, source_sha256, generation, dispatch_id, parser_id, media_type, byte_count, scope_digest. Enforce canonical UUID strings, lowercase SHA-256 values, exact integer-not-bool generation and byte count, exact PARSER_ID, application/pdf only and existing byte bounds. Scope_digest is opaque permission-scope binding, not a child name or client authority. Enforce source SHA-256, length and PDF signature before any engine call. Reject extra fields. Before calling shared HMAC/canonical helpers, preflight each envelope, signature and payload as exact bounded primitive fields, refusing nested/oversized values. Verify job envelope via existing HMAC contract and expiry (<=120s). Future trusted composition must provision dedicated job-scoped keys, never client/model credentials. Independent scan envelope must verify under a separate >=32-byte key and match ALL expected job fields plus scanner_id and status=clean, with its own expiry. Equal job/scan keys are rejected. Scanner_id is supplied by the trusted composition layer, bounded server asset identity (1–96 ASCII letters/digits/._-). This does not qualify the asset: live broker grants and approved runtime registry still gate dispatch/publication. Unavailable, non-clean, mismatched or expired scan cannot call document_factory.

Snapshot expected provenance before engine calls; a callback must not be able to broaden output authority by mutating caller dictionaries. No default engine factory is configured; when None, raise RuntimeUnavailable without importing the SDK. A qualified isolated worker will later supply a trusted factory that opens the data using the pinned SDK. Never load a plugin/module/path named by input. The factory injection is internal test/composition code, not user-configurable. Return the existing result schema: expected provenance fields, page_count, quality=needs_review and blocks(page,anchor,text). No public/shared promotion, role/mastery write or auto approval.

## Extraction and limits

Use the exact cached SDK’s basic document/page/textpage methods. Inspect source as data to confirm arguments. Require 1–MAX_PAGES; each page must have extractable non-whitespace text. Empty/image-only/blank pages are held rather than silently dropped in this limited PoC. Bound native-reported character counts BEFORE fetching text. Retrieve bounded chunks (<=2,000 chars per block), strict decoding, no rendering/bitmap/export/encoder/OCR/JS calls. Preserve text/notation (no normalization or silent decode-error ignore). Stable unique page/block anchors. Enforce MAX_TEXT, <=1,000 blocks, serialized MAX_OUTPUT and current validate_result. Fail closed on partial/malformed native values or a chunk that cannot be preserved under the contract. The cached SDK warns native range indices and returned string lengths can differ and get_text_range is UCS-2 limited: conservatively hold mismatched ranges/nonrepresentable text, never silently omit it. Actual fidelity and whether a later bounded Unicode path is needed remain untested. Accept no unsupported result fields.

Check the monotonic soft deadline (10s) before and after calls and between chunks. This is not a hard native hang/process/memory timeout: a future qualified parent watchdog must kill the isolated worker and enforce CPU/RAM/process/output limits. Document that limitation, do not claim OS isolation from these tests. Close text/page/document resources on success and EVERY failure, including cleanup failures; emit a bounded reason rather than raw document text or arbitrary native exception messages. Re-raise project contract failures using bounded codes without source dumps. No logging of content or keys.

## Test scope

Independent tests use authored byte markers and fake SDK-shaped objects only. Negative cases: signed field drift/extra fields/expiry/key misuse, source hash/size/type, scan unavailable/dirty/hash/job mismatch, no factory/import, oversized pages/chars/text/output, strict decoding, partial native results, deadline, malformed return types, and resource closure including exceptions. Preserve Arabic/German notation in fake extraction without claiming real extraction or teaching fidelity. Tests should assert authority/limits before any factory call and output needs_review/provenance; do not merely mirror helper branches.

The public ingestion API, actual SDK bridge, worker transport/OS launcher, reviewed asset activation and real PDF/quality evals remain separate and held. A successful fake-engine unit test is adapter logic evidence, not actual PDFium/scanner/isolation execution or F3 completion.
