# Authored worker process guard contract

20 November 2026 · DEV-010 / AUTH-013 · R040/R046. Implement an internal watchdog/pipe transport core for a future qualified parser worker. This is not an OS sandbox or a native SDK/scanner activation. Only authored standard-library fixture programs run in tests. Existing broker, factory default and asset registry remain disabled/unchanged.

Own workers/parser/process_guard.py. Standard library only; importable without Django/PDFium. Export WorkerError(ValueError) with bounded reason strings, immutable WorkerProgram(executable, script, script_sha256), WorkerLimits(timeout_seconds=10, input_bytes=65536, output_bytes=1048576, error_bytes=16384), WorkerResult(output, stderr_bytes, elapsed_seconds), and run_worker(payload, *, program=None, limits=None, cancelled=None). Unavailable program fails before spawn. Caller supplies only a reviewed server-owned program, never values from a job/model/client.

Validate payload exact bytes and <= input limit; limits exact bounded numeric primitives (bool/nonfinite/negative/oversized values fail): timeout >0 and <=30 seconds; input/output <=1 MiB; stderr <=64 KiB. Input may be empty. Program executable/script are absolute existing regular paths, script not symlink, script bytes <=256 KiB and SHA-256 equal trusted lowercase hex. Resolve interpreter path for venv compatibility; executable permission required. Script configuration is trusted composition, not an authorization grant. Future immutable worker-image/script review must address TOCTOU and filesystem trust; do not claim hashing alone establishes isolation.

POSIX implementation only; fail closed elsewhere before spawn. Spawn fixed argv [executable, '-I', '-u', script] with shell=False, close_fds=True, start_new_session=True, a fresh private temporary cwd and a minimal fixed environment excluding all inherited credentials, Python path/hooks, loader injection vars and application/database settings. No configurable arguments/env/cwd, no arbitrary module/plugin loading. The reviewed image's system site contents still require qualification; '-I' is not an OS boundary.

Use concurrently drained bounded stdin/stdout/stderr pipes so child output-before-input cannot deadlock. Bound stored stdout, count/discard stderr without returning/logging its contents. Deadline is monotonic and governs spawn/I/O/wait as far as the parent can control; hard-kill the owned child process group on timeout, cancellation, excess stdout/stderr, child failure or controller exception and always reap the direct child/close pipes. Cleanup also handles descendants retaining pipe descriptors after parent exit. Groups do not prevent a compromised child from escaping with setsid or filesystem/network access; cgroups/namespaces/limits remain required. Never signal a caller-supplied PID/group. No global process scan or hostwide cleanup.

cancelled is an internal zero-argument predicate polled during I/O, not a user command. If it raises, stop/clean the child with bounded controller error. Deadline cancellation must not require child cooperation. On nonzero exit/failure/limit/timeout/cancel return no partial stdout or raw stderr/exception; raise bounded WorkerError. Successful output is still untrusted bytes, not validated parser output or publication permission; caller must parse/verify with existing broker contracts. Result reports output and stderr byte count plus measured elapsed time only. No default logs or child content in messages.

Tests owned separately: authored local script fixtures only, no SDK, network, DB or real data. Assert default denial/script hash and input/limit checks before spawn; success bytes and private cwd; env sentinel not inherited; partial stdin with early child output drained; stdout and stderr flooding cap; timeout and cancellation of sleeping/ignoring child; a descendant retaining pipes can't hang the call; abnormal exit and callback exception redact private markers; successful/error cleanup reaps direct child, does not kill unrelated processes and removes temporary cwd. Bound test wall time and always clean authored processes in test finalizers. Do not run supplied source or remote install scripts. A passing real child-process test is watchdog evidence, not memory/CPU/network/OS sandbox or PDFium fidelity proof.
