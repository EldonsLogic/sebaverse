# Sebaverse shared rules

Read root AGENTS.md as canonical authority, then development/CURRENT-STATE.md and development/QUALITY-BAR.md before work. Run `python3 tools/brief.py <task ID>` for the task, its requirements and its gate instead of loading tasks.json, phase-gates.json or requirements.json whole. Read START-HERE.md, ENGINEERING_RULES.md, WORKFLOW.md and HANDOVER.md on a first session or when unsure of a procedure. QUALITY-BAR.md sets the standard for learning quality, interface, security, inference cost and proportional effort. Preserve the selected subject-independent architecture, source/requirement IDs and actual authorization boundaries. Claim task/file ownership, verify meaningful tests and record evidence; each phase must pass its required tests/review before the next starts. Commit/push reviewed milestones to the founder-authorized private EldonsLogic/sebaverse repo without rewriting others' history. No secrets, raw child data, fake results, automatic spending/deployments or historical output AGENTS overrides. All further shared details live in root rules and development/; do not fork a competing instruction set.
