## Naming brief and candidates

Promise: understandable help, visible progress and lasting independent learning. Personality: patient, capable, warm and precise; age-flexible for school learners, reassuring to guardians. Avoid magical intelligence, guaranteed grades, surveillance language and overly infantile presentation. Arabic and English spoken recall, spelling, transliteration, app-store search and future global use matter.

All names are unverified ideation, not availability recommendations. Do not buy domains, publish identities or register marks on this list alone. Gate G2: shortlist three with native Egyptian Arabic/English learners/parents, test pronunciation/spelling/negative associations, search Egyptian and target-territory trademarks (with counsel), commercial/company names, domains, app stores/social handles and confusingly similar education products. Record query/date/results/owner and legal clearance. A domain being free does not clear a trademark. Founder chooses with a documented rationale; create final wordmark/artwork only after selection. No winner is silently chosen.

## Identity direction

Proposed concept: a path of small understandable steps, represented through simple original geometric progress motifs rather than a generic robot. Deep teal primary, warm cream surfaces, restrained amber support accent; use separate semantic colors/icons. Bilingual wordmark spacing needs native review. Candidate typography: a readable Arabic sans paired with a compatible Latin sans; exact font files/licenses/performance and Arabic diacritics require verification before adoption. Product copy uses warm Egyptian Arabic for guidance, formal curriculum terms in MSA/English, and concise guardian explanations without false certainty.

## Draft tokens

Editable tokens are in design-tokens.json. Proposed primary #0B6058, text #16332F, canvas #F7F8F4, white surface, amber #E8B44D, danger #A12835. Color pairings require measured contrast; the palette is not a compliance claim. Spacing scale 4/8/12/16/24/32/48; type 14/16/20/28/36 with Arabic-adjusted line height ~1.65; radius 8/12/20; visible 3px focus indicator with verified contrast; 44px minimum target proposed; reduced-motion preference honored.

Components: bilingual app shell/navigation, lesson header with objective/source, transcript, hint ladder, independent-answer card, math block, source drawer, evidence/status chip, review queue, upload/rights/status panel, recorder with remaining minutes, accessible dialogs/errors, guardian digest, teacher review queue and usage/entitlement panel. Each defines default/focus/loading/disabled/error/empty/offline states. Status never relies only on color; unknown differs from failed. UI shows actionable plain-language errors and does not expose provider/stack details unless meaningful to the user's decision.

## UX flows and text wireframes

Student home: [course/edition + language] → [continue 10-minute activity] → [due review] → [what I can do, with evidence] → [my materials]. Lesson: [objective + source] / [short tutor turn] / [response field + mic] / [hint or explain differently] / [source drawer]. Independent check announces mode and exposes skip/I don't know; hints explicitly return to supported practice. Summary shows one demonstrated skill, uncertainty and next action.

Guardian onboarding: choose adult role → understandable purposes/notice → verify relationship through approved process → child profile/minimal age data → curriculum/grant → notification preferences. Refusal/withdrawal and disputed relationship have clear routes; payment does not substitute for consent. Guardian dashboard: child selector within verified relationships → evidence-backed skill summary → next steps → usage/plan → permissions/export/delete/help. Private chat is not the default dashboard.

Upload: select child/course/private material → rights/purpose declaration → quota/file check → processing progress → mapping/extraction review → ready sources → replace creates a version → withdraw/delete derived data. Errors say what to fix; no false official alignment label.

Teacher future: scoped class roster → assignment objective → learner evidence/uncertainty → review grading dispute → audited override/correction. School aggregate views suppress small/identifying cells. Founder reviewer interface is a narrower pilot capability, not the complete school product.

Voice: explicit start and remaining quota → mic indicator/transcript → confirm uncertain math → playback with pause/speed → interrupt → resume checkpoint/text fallback. Denied permissions and exhausted minutes preserve the text activity.

## Experience acceptance

Test narrow mobile viewport, slow network, keyboard-only, screen reader, RTL/LTR mixed fractions/units, zoom to 200%, recording permission denial and interrupted sessions. Proposed target WCAG 2.2 AA; verify current standard at implementation. User tests include student comprehension and guardian interpretation of uncertain progress. Gate G2 approves flows, terminology and tokens; visual polish cannot waive educational/privacy gates.
