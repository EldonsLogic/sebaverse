## Findings, most important first

1. **Effort is out of proportion to product progress.** Six days and 29 commits have produced an empty shell. F2 alone added about 130,000 lines, of which about 1,600 are application code and tests. Most of the rest is advisory triage for a synthetic, loopback-only database. No learner-facing function exists yet. Addressed by QUALITY-BAR.md section 2.

2. **The mandatory session read is about 310 KB (roughly 90,000 tokens).** WORKFLOW.md required 14 files in full, including two JSON registers of 53 KB and 67 KB, at the start of every session by every agent. Addressed by tiered loading and `tools/brief.py`, which gives a task brief in about 3 KB.

3. **The F2 exit is not committed or pushed.** `tasks.json` and `phase-gates.json` record F2 as passed, with new evidence and the U17 source file, but all of it is uncommitted on `main`. The remote still shows F2 in progress. Next agent: review and commit this checkpoint before F3 work starts.

4. **Live state files contradict each other.** CURRENT-STATE.md (15 November, committed) says F2 is in progress and held. The uncommitted gate file says passed. HANDOVER.md's "Current objective" and "Exact next safe steps" still describe F0. Update CURRENT-STATE.md in the same checkpoint as finding 3 and cut the stale HANDOVER.md sections.

5. **Records are hard to read.** Many files run words together ("15November", "noHigh/Critical", "realPG"). The next agent or the founder has to decode them. Addressed by QUALITY-BAR.md section 7; existing files can be repaired when next edited.

6. **The repository carries 32 MB of raw evidence.** `development/evidence/` holds CI logs of 300 KB, a zip archive and scanner dumps. `.git` is already 39 MB. Keep hashes and summaries in Git and bulk files as CI artifacts.

7. **The web client has no unit tests, no linter and no message catalog.** All Arabic copy is hard-coded in `web/src/app/App.tsx`, while the requirements call for Arabic, German and English. Fix before feature screens multiply.

8. **Styles bypass the design tokens.** `web/src/app/styles.css` redeclares colours as its own variables and contains 20 raw hex values; nothing reads `design/design-tokens.json`. Generate the CSS variables from the tokens file or check them against it.

9. **Fonts are heavy for mobile data.** Two variable TTF files of 332 KB and 360 KB load on first paint, and a third of 308 KB ships unused. Subset to the glyphs needed and serve WOFF2.

10. **Every response is `Cache-Control: no-store`,** including content-hashed assets (`backend/modules/core/middleware.py:34`). Correct for HTML and API; wasteful for hashed files once this serves real users.

11. **The single-page client cannot yet send a CSRF token.** `CSRF_COOKIE_HTTPONLY = True` (`backend/config/settings.py:52`) hides the cookie from script, and no endpoint or meta tag supplies the token. Harmless today because there are no write endpoints. Decide the mechanism in DEV-008 before the first one.

12. **Logs carry no usable signal.** `MetadataOnlyFormatter` emits only level and logger name. Private, but an incident could not be diagnosed. Add a request ID and a safe, allow-listed set of fields before F3 features land.

13. **Production settings are untested behind a proxy.** `SECURE_SSL_REDIRECT` is on without `SECURE_PROXY_SSL_HEADER`, which would loop behind a TLS-terminating proxy. Not urgent; record it for the deployment task.

14. **F3 gate suites have names but no commands.** That is acceptable before the phase starts, but DEV-007 should define real commands first so the gate cannot be met by assertion.

15. **Process weight.** Thirty role contracts, a roster, 14 process documents and three templates govern a codebase of about 700 application lines. Activate roles only when a second pair of eyes will change a decision.
