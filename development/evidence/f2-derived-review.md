## 15 November focused BusyBox finding review — CVE-2025-60876

Primary sources inspected live: [Alpine security tracker](https://security.alpinelinux.org/vuln/CVE-2025-60876), [BusyBox patch cover letter](https://lists.busybox.net/pipermail/busybox/2025-November/091839.html) and [actual proposed patch](https://lists.busybox.net/pipermail/busybox/2025-November/091840.html). The Alpine work item17872 returned403, so its discussion/maintainer disposition was not verified.

Observed supplier status: Alpine lists 3.24-main busybox1.37.0-r31 as possibly vulnerable; no fixed package was identified on that tracker. Do not describe r31 or the derived candidate as patched. Upstream's November2025 patch proposal modifies wget URL parsing to reject bytes at or below ASCII space before constructing requests. Its publication/review tags establish a proposed fix, not proof that the pinned Alpine binary includes it.

Trigger: a BusyBox wget invocation consumes a URL whose request target contains raw control bytes or space, enabling attacker-controlled outgoing HTTP request headers. This is a wget URL-input vulnerability, not evidence of direct exploitation through PostgreSQL's listening port. Three package matches (busybox, busybox-binsh and ssl_client) need exact package/component mapping; a shared source-package match does not by itself prove three independently reachable code paths. The affected applet remains present unless separately proven otherwise.

Conditional risk-review recommendation, not approval: a tightly bounded synthetic PostgreSQL migration experiment may support a documented Medium finding acceptance under the existing per-finding policy if the reviewed entrypoint/initialization/workload never invokes wget or consumes attacker-controlled URLs; container egress is constrained to the minimum needed (prefer an internal test network with no external route); no arbitrary init scripts, user uploads, shell hooks or package downloads run; and the exact image/version, evidence and limitation are bound to the one test invocation. Nonroot execution/read-only root alone does not prevent an injected outgoing request. Merely deleting a wget symlink also does not disable a multicall BusyBox applet callable as `busybox wget`.

Until these reachability/containment facts and remaining component reviews are recorded, keep the finding held. Even a justified local-only review must retain the scanner matches and cannot assert vendor fix, unrestricted safety, production suitability, release clearance or a phase pass. Fresh native/core checks and actual final source-to-runner identity binding remain separate.
