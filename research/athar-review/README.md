## Method and evidence

Forty-three selected files (880,906 bytes) were retrieved as data. Each decoded file matched the API byte count and Git blob hash; SHA-256 and pinned source URLs are preserved in [the snapshot manifest](source-snapshot.json). Source bytes remain in ignored audit scratch, with no source files, packs, weights or dependencies vendored into Sebaverse. We did not install, import, execute, run tests or exercise Athar. Test code demonstrates intended cases, not reproduced passing behavior. Reported author evaluation and synthetic demonstrations are not teacher, child, safety or learning validation.

Reviewed areas: deterministic graph/explanations, family cards, missing-record requests, report review, curriculum additions, spreadsheet/photo ingestion, accounts/class scope, privacy, dependencies, root license and stated future direction. This is selective source review, not a full vulnerability/secret scan or complete provenance audit. No model/provider terms, dependency licenses or content rights have been cleared for reuse.

## Rights and security disposition

Study concepts only. No Athar code, curriculum YAML, translated text, screenshots, models or weights are copied into the product. Future copying would require exact files/version, Apache license and applicable notice/change obligations, transitive dependency review, and separate model/data/content rights. The root license is not permission from textbook publishers. Ministry/secondary-source references and author-drafted prerequisite links require independent per-edition provenance and educator review; do not call the packs approved Egyptian curricula.

Do not port demo bootstrap permissions, shared installation identity, class-wide cross-subject access, raw-document model calls, model-derived active scores, unrestricted MCP write semantics, word-list-only Arabic safeguards, raw audit payloads or incomplete deletion. Fixed narratives still need input/fact validation and scoped rendering. Templates and a teacher checkbox cannot make an unsupported inference valid.

[Architecture selection and full feature dispositions](../../architecture/athar-derived-refinements.md) record accepted refinements, covered features, future candidates, acceptance and exclusions. Every implementation remains gated by its original requirements and phase. The separate AUTH-017 teaching demo continues under its own limited approval; nothing from this audit is injected into it.
