## Pack contents

- architecture/: system/data/runtime maps, 12 ADRs, API/subject/deployment contracts, all 99 requirements mapped to functions/phases/build-reuse, all 22 audited repo dispositions, decision manifest and auditor response template.
- registers/: full requirement/source/dependency/acceptance and decision/risk records.
- research/: both original research packs, 36 preserved reports/supporting evidence artifacts with original citations and pins.
- sources/: founder scope decisions, source catalog, historical context limits and limited primary-source checks.
- docs/, economics/, execution/, design/, tools/: full contextual specifications, cost assumptions/calculator, roadmap and phased agent prompts, current tokens and artifact validators.
- outputs/: historical design evidence and current brand kit; earlier routes are not current selections.

Only editable documentation/assets/research are exported. No application, installed dependency, raw child dataset, secret, Git internals or scratch directory included. Exact production release locks/provider/region/terms/spend/retention choices remain marked unknown until the appropriate phase; finalized architecture is not permission to invent those facts.
