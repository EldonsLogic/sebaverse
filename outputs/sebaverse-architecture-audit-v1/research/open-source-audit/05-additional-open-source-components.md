# Supporting components: shortlist and dependency limits

Audit date: 10 November 2026. These are focused source inspections, not complete product/security audits. Exact commits and license files are in [01](01-repository-inventory.md). Candidate presence does not mean it belongs in the pilot.

## Prioritized selection

| Priority / capability | Candidate and inspected interface | Decision | Qualification / cost |
|---|---|---|---|
| P0 retrieval storage | pgvector; Postgres extension vector operators, HNSW/IVFFlat | Adopt if retrieval evaluation beats lexical baseline | One database, no separate vector service; enforce student and curriculum filters before returning passages |
| P0 document parsing | Docling `DocumentConverter.convert/convert_all` | Adapt in a restricted worker | CPU/model memory and model licenses; preserve page provenance; Arabic scans and math require local evaluation |
| P0 assessments | Custom versioned item schema, deterministic marking, reviewed explanations | Build | Neither an LLM question generator nor a benchmark toolkit is a calibrated examination system |
| P0 learning memory | Custom learner-state tables plus immutable assessment events | Build | Keep evidence separate from inferred preferences and conversational summaries |
| P0 outcome analytics | SQL views and a small internal dashboard | Build | Avoid introducing a warehouse or business-intelligence platform for 20 students |
| P0 tracing | OpenTelemetry API `get_tracer`, spans; structured cost ledger | Adopt API; build domain metrics | Do not export raw student prompts by default |
| P0 evaluation | Promptfoo public `evaluate` export / CLI | Adapt for offline regression tests | Node >=22.22; disable telemetry, use synthetic/redacted fixtures, isolate custom providers and executable assertions |
| P1 prerequisite modeling | Adjacency table; NetworkX DAG validation offline | Build table; optionally adopt library | No graph database required for a few thousand concepts |
| P1 mathematical marking | SymPy symbolic equivalence over a restricted expression AST | Adapt in a bounded worker | `parse_expr` uses eval; never directly pass student strings to it |
| P1 spaced practice | py-fsrs | Adopt after assessment design | Scheduling review does not estimate broad curriculum mastery; defaults work without fitted student data |
| P1 OCR fallback | PaddleOCR `PaddleOCR(lang=...)` | Benchmark against Docling's chosen OCR | Avoid installing two complete OCR stacks until Arabic pages demonstrate a need |
| P1 speech recognition | faster-whisper `WhisperModel.transcribe` | Benchmark / fallback | CTranslate2 and model weights; GPU ownership is rarely economical for a tiny pilot |
| P1 low latency voice | Pipecat `PipelineWorker` and transports | Defer until conversational audio is proven essential | Stateful connections and audio workers add operational load; `PipelineTask` entry point is deprecated at this pin |
| P1 speech generation | Chatterbox multilingual source + supported hosted TTS adapter | Reject Chatterbox as maintained default; benchmark supported providers | Arabic code exists, but upstream declares retired; weight/speaker rights and Egyptian math fidelity remain unverified |
| P1 parent portal | Custom guardian-student relationship and progress summary | Build | This is a product and permission boundary; no standalone dashboard framework needed |
| P1 WhatsApp | Direct Meta Cloud API via a narrow HTTP adapter | Adapt service API | Not an open-source messaging network; approved templates, recipient verification, opt-out and country rate card needed |
| P1 billing | Egypt-capable gateway adapter, e.g. Paymob; own entitlements | Adapt payments; build entitlements | Recurring-payment enablement is account-specific; prepaid course/semester renewals are a valid fallback |
| P2 background jobs | Celery tasks with bounded retries and idempotency | Defer initially | Start with a durable Postgres jobs table and one worker from the same application; add a broker only when throughput/retry needs justify it |
| P2 rich AI trace UI | Langfuse | Defer | MIT core / separately licensed EE; current Compose includes Postgres, Redis, ClickHouse, object storage, worker and web services |
| Alternative LMS | Moodle or Frappe LMS | Conditional fallback, not pilot default | Mature course workflows do not remove the need for tutoring policy, learner state or Egyptian privacy design |

## Arabic and multilingual validation

Egyptian Arabic, MSA and English are separate evaluation slices. Include code-switching, school terminology, Arabic and Western numerals, negation, fractions, noisy low-cost microphones, hesitant speech and silence. Measure normalized WER/CER alongside critical mathematical entity accuracy; assess meaning changes separately. TTS needs native-speaker ratings for intelligibility, dialect authenticity and mathematical correctness. Do not use accent classification to infer sensitive student characteristics.

[Cohere's Arabic ASR release](https://cohere.com/blog/transcribe-arabic) describes an Apache-2.0 open-weight model and dialect/code-switching benchmarks. Treat its superiority claim as vendor-reported, not verified for children. It is a discovery candidate, not a pinned source audit in this pack. [Arabic ASR research](https://arxiv.org/abs/2306.02902) motivates dialect-specific testing, but does not choose a winner for this product.

No open TTS winner is established here. Benchmark current hosted speech with a replaceable adapter first; model weights, datasets, voice permissions and commercial terms are separate gates from a repository's code license.

## Focused open-source TTS finding

Chatterbox is pinned at `ab55923c27757c90cfcc407baa57dc25a7d25217` (2026-11-04), MIT source, package0.1.7. Its `src/chatterbox/mtl_tts.py` implements Arabic `ar`, `from_local`, `from_pretrained` and `generate`. The inspected multilingual call returns a complete waveform, not a streaming/cancellable contract, and reference-audio conditioning mutates the model instance. Model downloads default to mutable `main`; a Perth dependency follows Git `master`. The pinned README explicitly declares the project retired/unmaintained since August2026, despite older promotional prose remaining. A recent README commit does not make the runtime maintained. These source findings support deferring self-hosted TTS, not assuming Arabic synthesis is missing.

The [detailed static source audit](evidence/chatterbox-source-audit.md) includes immutable file/line links, model candidate SHA, separate weight/voice rights, concurrency and deployment constraints. No model weights, installation or inference were run. The official model card labels weights MIT, but a standalone model LICENSE file was not verified; no commercially cleared Egyptian voice is established. Do not expose voice cloning to pupils or assume self-hosting is cheaper at tiny utilization.

## Dependencies to avoid

Do not adopt LangChain + LlamaIndex + LightRAG + GraphRAG together. A filtered Postgres retriever and a bounded tool loop are enough to validate a course. Avoid a vector database, graph database, dedicated memory service, feature store, GPU inference cluster and event-stream platform until measured limits justify them. Do not add a deep KT framework to serve arithmetic Bayesian updates. Do not install all optional extras from any repository.

## Verification limits

Selected source, manifests and licenses were inspected at pinned commits. These supporting applications were not installed, started, load-tested or certified secure. Full dependency vulnerability scans and model license/provenance reviews are pre-build gates. No messages or payments were sent.
