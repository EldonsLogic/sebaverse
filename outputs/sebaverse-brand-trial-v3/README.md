# Sebaverse — new Arabic-first brand trials, v3

Three independent proposed directions, not a palette swap of the rejected logos. Name selected; no logo, font system, palette or slogan approved. Latin-only **Sebaverse** logo; Arabic-first product and messaging. Grade/age unspecified; German/uploaded curriculum is first use case, not the full identity.

| Route | Brand idea | Arabic typography | Proposed palette | Read |
|---|---|---|---|---|
| The useful margin / الهامش المفيد | A helpful explanation alongside the learner’s page | IBM Plex Sans Arabic | Cobalt, lime, quiet paper | [Guidelines](margin-guidelines.md) · [RTL preview](margin-preview.html) |
| The learning workshop / ورشة الفهم | Learning through small attempts and construction | Alexandria | Aubergine, yellow, warm paper | [Guidelines](workshop-guidelines.md) · [RTL preview](workshop-preview.html) |
| The clear index / المعرفة الواضحة | Sources and understandable progress | Noto Sans Arabic + Noto Naskh Arabic | Charcoal, restrained red, ivory | [Guidelines](index-guidelines.md) · [RTL preview](index-preview.html) |

Each includes concept-specific logo construction, measured flat color contrasts, type/layout rules, RTL/mixed-language behavior, Arabic slogans/copy, microcopy, product/marketing applications, motion, risk and implementation handoff. JSON tokens are editable. HTML previews are local reading/layout artifacts with system fallback fonts, not production mockups or finalized custom typography.

Official font-license references opened 11 November 2026: [IBM Plex Sans Arabic](https://github.com/google/fonts/blob/main/ofl/ibmplexsansarabic/OFL.txt), [Alexandria](https://github.com/google/fonts/blob/main/ofl/alexandria/OFL.txt), [Readex Pro](https://github.com/google/fonts/blob/main/ofl/readexpro/OFL.txt), [Manrope](https://github.com/google/fonts/blob/main/ofl/manrope/OFL.txt). Other Noto/Plex family files require exact version/notices verification before bundling. Generated visual boards are concept renderings, not editable vector masters or exact-font proofs. No production SVG master is claimed.

Recommendation to test: The useful margin has the clearest connection to uploaded curriculum and a helpful tutor. The workshop is more active; the index is more reserved. Founder feedback determines the next direction; none is approved by being generated.
